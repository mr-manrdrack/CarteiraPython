# CarteiraPython

**estatisicasb3.py**: Carteira Simulada em Python usando a biblioteca *yfinance*, Retorno Médio, CAPM, Correlação e Covariância.

**calculo_indicadores_financeiros.py** : Cálculos dos índices de: Liquidez seca, Liquidez Corrente, Giro do Ativo e Prazo. Para as empresas da carteira simulada, usando a biblioteca *yfinance* e extraindo informações do site **https://dados.cvm.gov.br/**, com saída no terminal e arquivo no formato .xlsx .

**calculos_trab_rob.py**: Cálculos para o último trabalho
